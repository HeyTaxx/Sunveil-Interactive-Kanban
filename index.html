Copy this configuration into your claude_desktop_config.json to give Claude Desktop direct access to read, create, and organize your Kanban cards and mindmaps.
%APPDATA%\Claude\claude_desktop_config.json 
{
  "mcpServers": {
    "sunveil-kanban": {
      "command": "node",
      "args": ["c:/Users/Admin/Documents/Sunveil Interactive Kanban/mcp-server.js"]

  }
}

The following 10 tools are available to the AI. Every action updates your live screen in real time!
kanban_get_board Retrieves the full Kanban board (columns, cards, counters, tags).
kanban_create_card Creates a new card in any column & initializes its visual mindmap.
kanban_move_card Moves a card to another phase or changes its order.
kanban_add_mindmap_node Adds thought bubbles, links, or notes to a card's mindmap.
kanban_get_card Returns comprehensive card details including all mindmap bubbles and sketches.
kanban_list_cards Filters cards by column or search query.
kanban_update_card Updates card title, tags, or description.
kanban_delete_card Removes a card from the board by its ID.
kanban_list_columns Lists all columns with IDs, titles, and colors.
kanban_create_column Adds a new phase column to the Kanban board.

GitHub Projects Integration & 2-Wege Sync

Verbinde Sunveil mit GitHub Projects v2. Alle Aufgaben, Issues und Pull Requests werden als Kanban-Karten geladen und Änderungen synchronisiert.

💡 Benötigte Scopes: repo und project. Hier direkt Token auf GitHub generieren ↗
Hintergrund Auto-Sync
Synchronisiert alle 30 Sekunden im Hintergrund & sofort bei Kartenverschiebungen
[Bereit] Warte auf Synchronisation...

🚀 So verbindest du GitHub Projects v2:

  1. Token erstellen: Gehe zu GitHub Token Settings und erstelle ein Personal Access Token mit den Rechten repo und project.
  2. In Sunveil eintragen: Füge das Token im Tab 'Verbindung' ein und klicke auf 'Token prüfen'.
  3. Projekt auswählen: Wähle dein gewünschtes GitHub Project v2 und das dazugehörige Status-Feld (z. B. "Status") aus.
  4. 2-Wege Synchronisation: Jede Karte auf dem Board kann nun verschoben oder editiert werden. Der Status wird live in GitHub Projects aktualisiert!
  5. Team-Kollaboration: Alle Mitarbeiter, die über Live Share oder im gleichen Netzwerk auf das Board zugreifen, sehen die synchronisierten GitHub-Karten in Echtzeit.

Sunveil Interactive Kanban installieren

Nutze Sunveil auf jedem Gerät: als eigenständige Desktop-App, Web-App oder auf Tablets & Smartphones.

🚀 1-Klick App Installation

Direkt im Browser (Chrome, Edge, Brave, Safari) als eigenständige fensterbasierte App ohne Adressleiste installieren.

🖥️ Windows Desktop (.exe / cmd)

Portable Version mit WebView2-Engine. Startet in Millisekunden ohne Installation über Start-Kanban.cmd oder Sunveil.exe.

💻 Entwickler & Git

Quelloffen und vollständig anpassbar. Ausführen mit Node.js:

npm start
