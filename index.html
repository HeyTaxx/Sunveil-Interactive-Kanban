🤖 Model Context Protocol (MCP) & AI Integration

Server Active 10 Tools Live 2-Way Sync
Copy this configuration into your claude_desktop_config.json to give Claude Desktop direct access to read, create, and organize your Kanban cards and mindmaps.
%APPDATA%\Claude\claude_desktop_config.json 
{
  "mcpServers": {
    "sunveil-kanban": {
      "command": "node",
      "args": ["c:/Users/Admin/Documents/Sunveil Interactive Kanban/mcp-server.js"]
    }
  }
}

💡 Tip: Restart Claude Desktop after saving. Claude will instantly gain access to kanban_get_board, kanban_create_card, kanban_move_card and all mindmaps!

Zero external npm dependencies — boots in milliseconds using the Node.js standard library.

The following 10 tools are available to the AI. Every action updates your live screen in real time!
kanban_get_board Retrieves the full Kanban board (columns, cards, counters, tags).
kanban_create_card Creates a new card in any column & initializes its visual mindmap.
kanban_move_card Moves a card to another phase or changes its order.
kanban_add_mindmap_node Adds thought bubbles, links, or notes to a card's mindmap.
kanban_get_card Returns comprehensive card details including all mindmap bubbles and sketches.
kanban_list_cards Filters cards by column or search query.
kanban_update_card Updates card title, tags, or description.
kanban_delete_card Removes a card from the board by its ID.
kanban_list_columns Lists all columns with IDs, titles, and colors.
kanban_create_column Adds a new phase column to the Kanban board.
